# game-save-sync

Keeps save games for non-Steam games in sync between a Windows PC and a Steam Deck,
using [Ludusavi](https://github.com/mtkennerly/ludusavi) for save discovery/backup and
[rclone](https://rclone.org) + Google Drive as the always-available middle copy.

See [PLAN.md](PLAN.md) for how it works, how to build and deploy it, and
what is left to do.

`docs/` holds the homepage and privacy policy served via GitHub Pages
(required for the Google OAuth consent screen).
