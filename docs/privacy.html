Privacy policy

game-save-sync · last updated 16 October 2026

What the app accesses

game-save-sync requests a single Google permission, drive.file. This lets it see and manage only the files and folders it creates itself in the signed-in user's Google Drive. It cannot read, list or change any other files in that Drive.

What data is stored

The app uploads copies of video game save files from the user's own devices to a folder in the user's own Google Drive, and downloads them back to the user's other devices. No other personal data is collected.

Sharing

Data is never sent to the developer or to any third party. Google Drive data is used only to sync save files between the user's own devices. There are no analytics, advertising or tracking. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Backups stay in the user's Google Drive until the user deletes them. Access can be revoked at any time from Google Account permissions.

Contact

Questions can be raised as an issue on the project repository.
