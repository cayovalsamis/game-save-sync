game-save-sync

Personal save-game sync between a Windows PC and a Steam Deck.

game-save-sync is a personal, non-commercial tool. It keeps PC game save files in sync between its author's own devices by storing backups in the author's own Google Drive, similar to Steam Cloud but for games outside Steam.

It is built on Ludusavi and rclone. It is not offered as a service to other users.
